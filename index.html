🖧 your own server (most reliable)
your own cobalt has no bot checks and no limits. on your pc, run:
docker compose up -d # in the repo folder (docker-compose.yml) node server.js # serves this page + proxies to cobalt
or without docker:
git clone https://github.com/imputnet/cobalt cd cobalt/api pnpm install echo "API_URL=http://localhost:9000/" > .env pnpm start
then open http://localhost:8080 — or from your phone on the same wifi, http://YOUR-PC-LAN-IP:8080. if the server isn't up yet, this page watches and connects on its own the moment it starts.
